# NoticeChatbot-Client

React + TypeScript + Vite 기반 클라이언트 프로젝트입니다.

## Run

```bash
pnpm install
pnpm dev
```

## Lint & Format

- Lint: `pnpm lint`
- Format: `pnpm format`
- Format Check: `pnpm format:check`

### Rules

- ESLint: `eslint.config.js`
- Prettier: `.prettierrc.json`
- Ignore: `.prettierignore`
